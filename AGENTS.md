## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Writing conventions

Every change to an English page must be mirrored on the Spanish page, and vice versa.

### Names

- The club's full name is **Club de Vuelo Libre El Peñón**. The only accepted short form is **Club Peñón** (or "the Club" / "el Club" once context is clear). Never write "Club El Peñón".
- **El Peñón** alone refers to the site (the mountain / launch), not the club.
- The Valle de Bravo club is the **Club de Vuelo y Vela de Valle de Bravo** (*Vuelo y Vela*, in that order).
